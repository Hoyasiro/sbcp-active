# 삼복출프(SBCP) 출결 프로그램 사용설명서 (v1.7)

학생이 **번호 2자리**로 등·하원을 체크하면 출석률·연속 출석·체류 시간이 자동으로 집계됩니다.
매주 **지난주 리포트**를 AI가 자동으로 써 주고, 학생들은 등원할 때 자기 리포트를, 출결 데스크 보드에서 친구들의 리포트를 봅니다.

이 프로그램은 **학원 PC 한 대에서만** 동작합니다. 인터넷 사이트가 아니며, 모든 데이터는 그 PC의 브라우저 안에 저장됩니다.
인터넷은 **AI 문장을 만들 때만** 필요합니다.

---

## 1. 설치하기

### 1-1. 설치 전에: 기존 데이터 백업 (이미 쓰고 계셨다면)

예전 버전(`index.html`)을 쓰고 계셨다면 **먼저 백업 파일을 받아 두세요.**

1. 예전 프로그램을 평소처럼 엽니다.
2. 왼쪽 **데이터 관리** → **⬇️ 전체 데이터 백업** 을 누릅니다.
3. `다운로드` 폴더에 백업 파일(`acad_backup….json`)이 생겼는지 확인합니다.

### 1-2. 설치 파일 실행

1. **`SBCP_Setup_v1.7.exe`** 를 더블클릭합니다. (이미 설치된 PC라면 설치 파일 대신 [7절 업데이트 파일](#7-업데이트-제거)을 쓰세요)
2. 파란 창 **"Windows의 PC 보호"** 가 나오면 **추가 정보** → **실행** 을 누릅니다.
   (학원용으로 직접 만든 프로그램이라 나오는 경고입니다)
3. 설치 화면에서 **다음** 을 누릅니다.
4. **설치 위치**는 그대로 두는 것을 권장합니다.
5. **구성 요소**에서 원하는 항목을 고릅니다.

   | 항목 | 설명 | 권장 |
   |---|---|---|
   | 프로그램 | 출결 프로그램 + 사용설명서 (필수) | ✅ |
   | 바탕화면 바로가기 | 바탕화면에 **삼복출프 출결** 아이콘 | ✅ |
   | Windows 시작 시 자동 실행 (전체 화면) | PC를 켜면 프로그램이 **전체 화면(F11)으로** 자동으로 열림 | ✅ (13:30 자동 리포트를 놓치지 않음) |

6. **설치** 를 누릅니다. PC에 크롬과 엣지가 모두 있으면 **"어떤 브라우저로 열까요?"** 창이 뜹니다.
   - **예전에 출결 프로그램을 열던 브라우저**를 고르세요. (크롬 = 예, 엣지 = 아니요)
   - 출결 데이터는 브라우저마다 따로 저장되므로, 다른 브라우저를 고르면 데이터가 안 보입니다.
   - 한 번 고르면 기억하므로 업데이트할 때는 다시 묻지 않습니다.
7. **마침** 을 누르면 프로그램이 전체 화면으로 열립니다.

> 관리자 권한은 필요 없습니다. 설치 위치: `C:\Users\(사용자)\AppData\Local\SBCP`
> 시작 메뉴 **삼복출프** 폴더에 프로그램·사용설명서·제거 아이콘이 생깁니다.

### 1-3. 기존 데이터가 보이는지 확인

- **예전과 같은 브라우저**(크롬이면 크롬, 엣지면 엣지)로 열리면 **기존 데이터가 그대로 보입니다.** 따로 할 일이 없습니다.
- 학생 명단이 기본값(김민준·이서연·박지훈 3명)으로 보이면, 1-1에서 받은 백업 파일로 복구합니다. → [5-2 복구하기](#5-2-복구하기-불러오기)

## 2. 처음 한 번: AI 키 등록

AI가 리포트 문장을 쓰려면 Google Gemini **API 키**가 필요합니다.
키가 없어도 출결·통계·랭킹·보드의 **숫자는 모두 정상**이며, AI 한마디만 "준비 중"으로 표시됩니다.

### 2-1. 키 발급 (무료)

1. 크롬에서 **https://aistudio.google.com/apikey** 에 접속해 구글 계정으로 로그인합니다.
2. **Create API key** (API 키 만들기)를 누릅니다.
3. 만들어진 키(`AIza…`로 시작)를 **복사**합니다.

### 2-2. 프로그램에 등록

1. 프로그램 왼쪽 **설정** → **🤖 AI 연결** 칸으로 갑니다.
2. 입력칸에 키를 **붙여 넣고**(Ctrl+V) **저장** 을 누릅니다.
3. **연결 테스트** 를 누릅니다. "✅ AI 연결 성공!" 과 예시 문장이 나오면 끝입니다.

> 🔒 키는 이 PC의 브라우저에만 저장되고 **백업 파일에는 들어가지 않습니다.**
> PC를 바꾸거나 브라우저 데이터를 지운 뒤에는 키를 다시 등록해 주세요.
> 키가 새어 나간 것 같으면 2-1 페이지에서 해당 키를 삭제하고 새로 만드세요.

### 꼭 지켜 주세요

- 13:30~14:00에는 **프로그램 화면이 열려 있어야** 자동 생성이 됩니다. (브라우저 창 최소화는 괜찮습니다)
- **절전 모드를 끄세요.** 설정 → 시스템 → 전원 → "절전 모드" 를 **안 함** 으로. (화면 끄기는 괜찮습니다)
- 바로가기로 켜면 **전체 화면**으로 열립니다. 나가기: `F11` 또는 `Esc`. 다시 들어가기: `F11`

### 화면 설정 (v1.7)

| 항목 | 기본값 | 설명 |
|---|---|---|
| 사이드바 (왼쪽 메뉴) | **숨기기** | 화면을 넓게 쓰도록 숨겨 둡니다. 왼쪽 위 **☰** 버튼을 누르면 메뉴가 열리고, 메뉴를 고르거나 바깥을 누르면 닫힙니다. **설정 → 화면 설정**에서 "항상 표시"로 바꿀 수 있습니다. |
| 시작할 때 전체 화면 | **켜기** | 바로가기로 켜면 바로 전체 화면. 다른 방법으로 열었을 때는 **첫 번호 입력이나 클릭** 때 전체 화면으로 바뀝니다. |
| 화면 크기 맞춤 | **자동** | 모니터 크기에 맞춰 화면 전체를 비율대로 줄입니다(브라우저 "축소"를 자동으로 하는 것). 1600×900 모니터는 약 83%로 맞춰집니다. 원하면 100/90/80/70%로 고정할 수 있습니다. |

> 브라우저 자체의 확대/축소(Ctrl + 마우스 휠, Ctrl + -)는 **100%** 로 두세요. (Ctrl + 0 으로 되돌림)
> 자동 맞춤과 겹치면 화면이 지나치게 작아집니다.
- 휴원일(공휴일·자체 휴강)은 **설정 → 휴원일 관리** 에 미리 등록하세요. 출석률과 연속 출석 계산에서 빠집니다.
  음력 공휴일(설·추석·석가탄신일)과 대체공휴일은 직접 추가해야 합니다.

## 4. 지난주 리포트와 친구 보드

### 4-1. 자동 생성

- 평일 **13:30**에 지난주(월~금) 출석한 학생 전원의 리포트를 AI가 한 명씩 작성합니다.
  무료 키의 사용량 제한에 걸리지 않도록 학생 사이에 간격을 두므로 **40명 기준 5~10분** 정도 걸립니다.
- **14:00**에는 실패하거나 빠진 학생만 다시 시도합니다. PC를 늦게 켰다면 켜자마자 1차, 끝나는 대로 2차가 돌아갑니다.
- 진행 상황: **주간 리포트** 화면 아래 **"지난주 리포트 자동 생성"** 칸
  - `13:30 시도함` · `14:00 시도함`, `n건 생성 · n건 미생성`
  - 미생성이 남으면 **[미생성분 지금 생성]** 으로 바로 다시 시도할 수 있습니다.
- 주말에는 동작하지 않습니다. 지난주 출석이 0일인 학생과 전체 휴원 주는 AI 문장을 만들지 않습니다.

### 4-2. 학생에게 보이는 것

- **등원 팝업**: 지난주 나의 등급·출석·연속·평균 체류 + AI 한마디
  - 리포트가 만들어지기 전(13:30 이전)에 등원하면 그날은 **통계만** 보이고, **다음 등원부터** AI 한마디가 보입니다.
- **친구 보드** (출결 데스크 오른쪽):
  - 한 번에 **3명**의 리포트가 보이고, 4초마다 한 칸씩 위로 올라갑니다. (한 명의 리포트가 약 12초 동안 화면에 머묾)
  - 글자 크기는 화면 크기에 맞춰 자동으로 조절됩니다. (1920×1080 전체 화면 기준 세 칸이 꽉 차게)
  - 위쪽의 **‹ ›** 화살표로 앞뒤 친구로 직접 넘길 수 있습니다.
  - **❚❚** 를 누르면 잠시 멈춰 천천히 읽을 수 있습니다. 버튼이 **▶ 10** 처럼 바뀌어 남은 시간을 보여 주고, **▶** 를 누르지 않아도 **10초 뒤 저절로 다시 돕니다.** (멈춘 동안 화살표를 누르면 10초를 다시 셉니다)
  - 오른쪽 위 **드롭다운**으로 보고 싶은 친구를 고르면 그 친구가 맨 위에 분홍 테두리로 고정되고, 20초 뒤 다시 순환합니다.
  - 버튼을 누른 뒤에도 커서는 번호 입력칸으로 돌아가므로 다음 학생이 바로 번호를 입력할 수 있습니다.
  - 지난주 출석이 0일인 학생은 순환에 나오지 않습니다(드롭다운으로 고르면 응원 문구만 보임).
  - AI 문장은 친구들이 함께 보는 글이라 **비교·질책 없이** 격려 위주로 작성됩니다.

## 5. 데이터 백업 · 복구

모든 데이터는 **이 PC의 브라우저 안**에 저장됩니다. 다음 경우 데이터가 사라지거나 안 보일 수 있으니 **백업 파일이 유일한 안전장치**입니다.

- 브라우저 **인터넷 사용 기록 삭제**에서 **"쿠키 및 기타 사이트 데이터"** 를 체크하고 지움 ← 가장 흔한 원인
- 다른 브라우저로 열림 (크롬 ↔ 엣지) 또는 **시크릿 창**
- PC 교체·포맷

> 데이터 관리 화면 맨 위에 **마지막 백업이 며칠 전인지** 표시됩니다. 7일이 지나면 프로그램을 켤 때 알림이 뜹니다.

### 5-1. 백업하기

1. **데이터 관리** → **⬇️ 전체 데이터 백업 (내보내기)**
2. `다운로드` 폴더에 **`acad_backup_2026-10-01.json`** 처럼 날짜가 붙은 파일이 저장됩니다.
3. **USB나 클라우드(구글 드라이브 등)에도 한 부** 복사해 두세요.

| 백업에 포함 | 포함 안 됨 |
|---|---|
| 학생 명단, 전체 출결, 연속·월간 통계, 휴원일, 학원 설정, 지난주 리포트(최근 8주) | AI 키, 리포트 생성 이력 목록, 화면 테마 |

> ⚠️ 백업 파일은 **메모장·엑셀로 열어서 저장하지 마세요.** 한 글자만 바뀌어도 복구가 안 될 수 있습니다.
> 메신저(카카오톡 등)로 옮길 때는 **ZIP으로 압축**해서 보내세요.

### 5-2. 복구하기 (불러오기)

⚠️ 복구하면 **지금 데이터가 백업 파일의 내용으로 전부 바뀝니다.**

1. (권장) 지금 데이터부터 **5-1 백업**을 한 번 합니다. 잘못 복구해도 되돌릴 수 있습니다.
2. 프로그램을 **평소 쓰는 방법**(바탕화면 아이콘)으로 엽니다. **시크릿 창은 안 됩니다.**
3. **데이터 관리** → **⬆️ 백업 파일 불러오기 (복구)** 를 누릅니다.
4. **`acad_backup_날짜.json`** 파일을 고릅니다. 가장 최근 날짜를 고르세요.
   - 예전 이름인 `acad_backup.json`, `acad_backup (1).json` 도 불러올 수 있습니다.
   - ❌ CSV 파일(`출결기록_….csv` 등)은 엑셀 열람용이라 복구에 쓸 수 없습니다.
5. 확인 창에 **파일 이름·백업 시각·학생 수·출결 기간**이 나옵니다. 맞으면 **확인**.
6. "✅ 데이터 복구가 완료되었습니다" 후 화면이 새로고침됩니다.
7. **학생 관리**에서 학생 수를 확인합니다.

### 5-3. 복구 오류가 날 때

| 화면에 나온 메시지 | 원인 | 해결 |
|---|---|---|
| JSON 백업 파일(.json)만 불러올 수 있습니다 | CSV·엑셀 등 다른 파일을 고름 | `acad_backup…json` 을 고르세요. 확장자가 안 보이면 탐색기 **보기 → 표시 → 파일 확장명** 을 켜세요. |
| 백업 파일 내용이 손상되었습니다 (JSON 형식 오류) | 파일을 메모장·엑셀로 열어 저장함 / 다운로드가 끊김 / 메신저 전송 중 변형 | 다른 날짜의 백업 파일로 시도하세요. 원본 파일은 열지 말고 보관하세요. |
| 올바른 백업 파일이 아닙니다 — 학생 명단이 없습니다 | 이 프로그램이 만든 파일이 아닌 JSON | `acad_backup` 으로 시작하는 파일인지 확인하세요. |
| …번째 학생 정보가 손상되었습니다 | 파일을 직접 고치다 번호·이름이 빠짐 | 고치지 않은 원본 백업 파일을 쓰세요. |
| 파일을 읽지 못했습니다 | USB가 빠졌거나, 클라우드에만 있고 PC에 내려받아지지 않음 | 파일을 **바탕화면에 복사**한 뒤 다시 고르세요. |
| 브라우저 저장 공간에 기록하지 못했습니다 | 시크릿 창이거나 저장 공간 부족 | **일반 창**(바탕화면 아이콘)에서 다시 시도하세요. |
| 복구는 됐는데 나중에 다시 사라짐 | 복구한 브라우저와 평소 여는 브라우저가 다름 | [6절 Q1](#q1-학생출결-데이터가-전부-사라졌어요) |

## 6. 문제 해결

### Q1. 학생·출결 데이터가 전부 사라졌어요

1. **브라우저가 바뀌지 않았는지** 확인하세요. 데이터는 브라우저마다 따로 저장됩니다.
   - 윈도우 업데이트 후 **기본 브라우저**가 크롬 ↔ 엣지로 바뀌는 경우가 있습니다.
     예전 브라우저로 다시 바꾸면(설정 → 앱 → 기본 앱) 데이터가 다시 보입니다.
2. **시크릿 창**으로 열려 있지 않은지 확인하세요.
3. 브라우저 기록 삭제로 지워졌다면 **백업 파일로 복구**하세요. → [5-2](#5-2-복구하기-불러오기)

### Q2. AI 한마디가 계속 "준비 중"이에요

1. **설정 → AI 연결**에서 "✅ 등록됨"인지 확인하고 **연결 테스트**를 눌러 보세요.
2. "키가 올바르지 않거나…" → 키를 다시 복사해 등록하세요(앞뒤 공백 없이).
3. "AI 서버가 혼잡합니다" → Google 쪽 일시 문제입니다. 14:00 재시도나 **[미생성분 지금 생성]** 으로 다시 시도하세요.
4. "인터넷에 연결되어 있지 않습니다" → 인터넷 연결을 확인하세요.
5. 13:30~14:00에 PC가 꺼져 있었거나 절전 상태였다면, 프로그램을 열어 두면 자동으로 이어서 생성합니다.

### Q3. 자동 생성 칸에 "AI 키가 등록되지 않아 자동 생성이 멈춰 있습니다"

키를 등록하면(2절) 바로 이어서 생성을 시작합니다.

### Q4. 보드에 특정 학생이 안 나와요

- 지난주 출석이 0일인 학생은 순환에서 빠집니다. 드롭다운으로 고르면 볼 수 있습니다.
- 새로 등록한 학생은 출석한 주가 끝난 **그다음 주**부터 보드에 나옵니다.

### Q5. 잘못된 파일로 복구해 버렸어요

1. 복구 **전에 받아 둔 백업**이 있으면 그 파일로 다시 복구합니다.
2. 없다면 복구 직전 데이터가 브라우저에 한 벌 보관되어 있습니다. 프로그램 화면에서 `F12` → **Console** 탭에 아래 한 줄을 붙여 넣고 Enter 합니다.
   (처음에 경고가 나오면 안내대로 `allow pasting` 을 입력하고 Enter 한 뒤 다시 붙여 넣으세요.)
   ```
   localStorage.setItem('acad-atd-03_1.4', localStorage.getItem('acad-atd-03_1.4-before-restore')); location.reload();
   ```

### Q6. 글꼴이 평소와 달라 보여요

인터넷이 끊겨 있으면 웹 글꼴 대신 윈도우 기본 글꼴로 보입니다. 기능에는 영향이 없습니다.

### Q7. PC를 켰는데 전체 화면이 아니에요

- 브라우저가 이미 백그라운드에서 켜져 있으면 전체 화면 옵션이 무시됩니다. 엣지의 **"시작 부스트"**, 크롬의 **"Chrome이 닫혀도 백그라운드 앱 계속 실행"** 을 끄면 해결됩니다. (브라우저 설정 → 시스템)
- 그래도 첫 번호 입력이나 클릭 때 전체 화면으로 바뀝니다(설정 → 화면 설정 → "시작할 때 전체 화면" 켜기).
- 바로 전환하려면 `F11` 을 누르세요.

### Q8. 화면이 너무 작거나 잘려 보여요

- 브라우저 확대/축소가 100%인지 확인하세요 (`Ctrl + 0`).
- **설정 → 화면 설정 → 화면 크기 맞춤** 을 "자동"으로 두세요. 설정 화면에 현재 화면 크기와 적용 비율이 표시됩니다.

## 7. 업데이트 · 제거

### 업데이트 (새 버전이 나왔을 때)

이미 설치된 PC는 **다시 설치할 필요가 없습니다.** 새 버전마다 함께 나오는 **업데이트 파일**만 실행하면 됩니다.

| 파일 | 언제 쓰나 |
|---|---|
| `SBCP_Update_v버전.exe` | **이미 설치된 PC** — 프로그램 파일만 새것으로 바꿈 |
| `SBCP_Setup_v버전.exe` | 처음 설치하는 PC, 또는 바로가기를 다시 만들고 싶을 때 |

1. (권장) **5-1 백업**을 한 번 합니다.
2. **`SBCP_Update_v버전.exe`** 를 더블클릭합니다. ("Windows의 PC 보호" 창이 나오면 **추가 정보 → 실행**)
3. 몇 초 뒤 "업데이트가 끝났습니다" 창이 뜹니다. **예**를 누르면 프로그램이 열립니다.
   - 설치 위치는 자동으로 찾습니다. 고를 것이 없습니다.
   - 바로가기, 자동 실행 설정, 출결 데이터, AI 키는 **그대로 유지**됩니다.
   - v1.7 업데이트는 기존 바로가기를 **전체 화면으로 켜지도록** 바꿉니다. 이때 한 번 "어떤 브라우저로 열까요?" 창이 뜰 수 있습니다(1-2절 6번).
4. 이미 열려 있던 프로그램 창은 **F5**(새로고침)를 누르세요.
5. 새 버전으로 처음 열리면 화면 아래에 **"✅ v버전 업데이트가 적용되었습니다"** 알림이 한 번 뜹니다.
   왼쪽 메뉴 맨 아래의 버전 표시(`Desktop Edition v버전`)로도 확인할 수 있습니다.

> 업데이트 파일이 "설치되어 있지 않습니다"라고 하면, 그 PC에는 설치 파일(`SBCP_Setup`)로 먼저 설치하세요.
> 예전처럼 `index.html` 을 직접 열어 쓰던 PC가 여기에 해당합니다.

### 제거

- 시작 메뉴 → **삼복출프** → **삼복출프 제거**, 또는 설정 → 앱 → **삼복출프 출결** → 제거
- 프로그램 파일과 바로가기만 지워지고, **출결 데이터는 브라우저에 남아 있습니다.**
  완전히 지우려면 먼저 백업한 뒤 브라우저의 사이트 데이터를 삭제하세요.
