# 삼복출프 (SBCP) — 학원 출결 + AI 지난주 리포트

학생이 **2자리 번호**로 직접 등·하원을 체크하면 출석률·연속 출석·체류 시간을 코드가 자동으로 집계합니다.
AI(Gemini)는 그 집계 결과를 **리포트 문장으로 옮기는 일만** 맡습니다.

**학원 PC 한 대에 설치해서 쓰는 프로그램**입니다. 인터넷 사이트가 아니며 서버도 없습니다.
- 데이터는 그 PC의 브라우저 안에 저장하고, JSON 백업 파일로 보관·복구합니다.
- 인터넷은 AI 문장을 만들 때만 사용합니다.

1. 설치가 끝나면 바탕화면의 **삼복출프 출결** 아이콘으로 엽니다.
2. 처음 한 번 **설정 → AI 연결**에 Gemini API 키를 등록합니다.

## 폴더 구조

```
sbcp-active/
├── index.html              화면 (개발용 원본)
├── css/style.css           디자인
├── js/main.js              출결·집계·AI 호출·보드 로직
├── docs/
│   ├── 사용설명서.md        사용자용 설명서 (설치 파일에 HTML로 포함)
│   └── 서비스기획서.md      기능 명세
├── installer/
│   ├── sbcp.nsi            처음 설치용 스크립트 (NSIS)
│   ├── sbcp_update.nsi     업데이트용 스크립트 (프로그램 파일만 교체)
│   ├── common.nsh          공통: 브라우저 찾기 + 전체 화면 바로가기
│   └── sbcp.ico            아이콘
├── tools/build.py          설치 파일 빌드
└── release/
    ├── SBCP_Setup_v1.7.exe  처음 설치용
    └── SBCP_Update_v1.7.exe 업데이트용
```

개발 중에는 `index.html` 을 브라우저로 바로 열어 확인할 수 있습니다(css·js 폴더를 함께 읽음).
설치 파일에는 이 셋을 한 파일로 합친 `SBCP.html` 이 들어갑니다.

## 설치 파일 다시 만들기 (개발자용)

코드를 고친 뒤 새 설치 파일을 만들 때:

```bash
pip install markdown pillow        # 처음 한 번
sudo apt install nsis              # Ubuntu (Windows는 https://nsis.sourceforge.io 에서 설치)
python3 tools/build.py
```

- `build/SBCP.html`: index.html + css + js 합본
- `build/manual.html`: docs/사용설명서.md → HTML
- `release/SBCP_Setup_v<버전>.exe`, `release/SBCP_Update_v<버전>.exe`: 버전은 `js/main.js` 의 `APP_VERSION` 에서 읽습니다. 예전 버전 파일은 자동으로 지웁니다.

**새 버전을 낼 때**
1. `js/main.js` 의 `APP_VERSION` 과 `WHATS_NEW`(업데이트 알림 문구), `index.html` 의 버전 표기를 올립니다.
2. `python3 tools/build.py` 로 두 파일을 만듭니다.
3. 이미 설치된 PC에는 **`SBCP_Update_…exe`만** 전달합니다.

> 저장 이름 `STORAGE_KEY`(`acad-atd-03_1.4`)는 **바꾸지 마세요.** 바꾸면 기존 출결 데이터를 읽지 못합니다.

## 설계 요약

**판정은 코드, 문장은 AI.** 출석률·등급·연속 출석은 전부 `js/main.js` 가 계산하고, AI에게는 확정된 숫자와 등급만 넘겨 문장만 쓰게 합니다. 같은 데이터로 몇 번을 만들어도 등급이 바뀌지 않게 하기 위해서입니다.

| 항목 | 기준 |
|---|---|
| 운영일 | 월~금 중 등록 휴원일 제외 |
| 등급 | 출석률로만 판정. 최고 100% / 양호 80%↑ / 보통 60%↑ / 주의 60% 미만 |
| 연속 출석 | 직전 운영일에 출석했으면 +1 (주말·휴원일은 건너뜀) |
| 체류 시간 | 하원 시각 − 등원 시각. 하원 미체크는 0분으로 평균에 포함 |
| AI 호출 | 브라우저에서 Gemini 직접 호출, 타임아웃 25초, 자동 재시도 없음(14:00 슬롯이 재시도 담당) |
| 문장 톤 | 학부모 발송용 / 학생 열람용 / 지난주 보드용(비교·질책 금지) |
| 데이터 | 브라우저 저장소(localStorage). JSON 백업 파일로 보관·이전 |

자세한 판정 기준, 예외 처리, 캐시 설계는 [`docs/서비스기획서.md`](docs/서비스기획서.md)에 있습니다.

## 개발 로그

### v1.7

- **전체 화면 자동 실행**: 브라우저는 보안상 웹페이지가 사용자 조작 없이 전체 화면이 되는 것을 막습니다. 그래서 바로가기가 브라우저를 `--start-fullscreen` 으로 직접 켜게 했습니다. 브라우저마다 출결 데이터가 따로 저장되므로 설치 때 브라우저를 고르게 하고 그 선택을 기억합니다. 브라우저가 이미 떠 있어 옵션이 무시되는 경우에는 첫 입력·클릭 때 화면 안에서 전체 화면으로 바꿉니다.
- **화면 자동 맞춤**: 1600×900에서 브라우저를 80%로 줄여야 맞던 문제가 있었습니다. 레이아웃을 화면마다 따로 다듬는 대신 1920×1080 설계를 그대로 비율 축소(CSS zoom)했습니다. `100vh` 높이도 같이 줄어드는 문제는 높이를 배율로 나눠 보정했습니다.
- **보드 버튼과 입력칸**: 테스트 중 보드 버튼을 누르면 키보드 초점이 버튼에 남아, 다음 학생의 번호 입력이 사라지는 문제를 발견해 고쳤습니다.
- **같은 모양 버튼 충돌**: 설정 화면에 리포트 톤 버튼과 같은 모양(`.tone-btn`)을 쓰자 리포트 톤 처리 코드가 설정 버튼까지 잡았습니다. 선택 범위를 리포트 화면으로 좁혔습니다.

### v1.6

- **보드 3명 표시**: 1920×1080에서 한 명분 카드 아래가 비어 보여 세 명으로 늘렸습니다. 세 카드가 칸 높이를 똑같이 나누게 했습니다. 화면 크기(최대화 창 / F11 전체 화면)와 문장 길이에 따라 남는 공간이 달라서, 글자 크기를 실제 높이로 계산해 세 카드에 공통으로 적용합니다.
- **업데이트 파일**: 프로그램이 HTML 한 파일이라 업데이트는 그 파일만 바꾸면 됩니다. 설치 마법사를 다시 거치지 않도록 설치 위치를 레지스트리에서 찾아 파일만 바꾸는 작은 실행 파일을 따로 만들었습니다.

### v1.5 — 2026년 10월 운영 버전 (학원 PC 전용 전환)

- **로컬 전용 전환**: 인터넷 배포(Vercel)는 미션 제출용이었습니다. 실제 운영은 학원 PC에서 HTML을 열고 JSON으로 백업하는 방식이어서, 서버와 배포 설정을 모두 걷어냈습니다.
- **AI 직접 호출**: 서버가 없으면 키를 숨겨 줄 곳이 없습니다. 대신 Gemini가 로컬 파일(`Origin: null`)에서 오는 요청을 허용하는 것을 확인했고, 키는 PC 한 대의 브라우저에만 두어 백업 파일에 섞이지 않게 분리했습니다.
- **설치 파일**: 사용설명서와 실행 파일을 한 번에 전달하려고 NSIS 설치 파일을 만들었습니다. 관리자 권한 없이 설치되고, 설치·제거가 브라우저 데이터에 영향을 주지 않습니다. 크롬·엣지는 모든 로컬 HTML 파일이 저장소를 공유하므로, 설치 위치가 달라도 기존 데이터가 그대로 보입니다.
- **방향 전환**: 카카오톡 등 외부 알림은 사업자 심사와 연동 역량이 부족해 보류했습니다. 대신 리포트를 **학원 안에서 학생들이 서로 보는 방식**으로 바꿨습니다.
- **연속 출석 휴원일 반영**:
  - 기존 `prevWeekday()` 는 주말만 건너뛰어, 휴원일이 낀 주에는 연속이 끊겼습니다.
  - `prevOperatingDay()` 로 바꾸고, 연속 여부를 "직전 운영일에 출석했는가"로 판단하게 했습니다.
- **자동 생성 시각**: 데스크 PC가 13:30쯤 켜지는 환경에 맞췄습니다. 테스트 중 Gemini가 일시적으로 503(혼잡)을 반환하는 것을 확인해, 실패분만 다시 시도하는 14:00 슬롯을 두었습니다.
- **복구 오류 개선**:
  - 실패 후 같은 파일을 다시 고르면 반응하지 않던 문제(파일 선택값 초기화 누락)를 고쳤습니다.
  - 저장에 실패해도 "성공"으로 표시되던 문제를 고쳤습니다.
  - 백업 파일 이름이 늘 같아 `(1)`, `(2)` 가 붙은 옛 파일을 고르기 쉬워서, 이름에 날짜를 붙였습니다.
- **설정 화면 오류 수정**: 학원 정보 입력칸이 HTML에서 빠져 있어, 설정 화면을 열 때마다 스크립트가 중단되었습니다. 그래서 휴원일 목록과 버전 표시가 그려지지 않았습니다. 입력칸을 복원했습니다.

## AI 기능 확장 설계

앞으로 AI 기능을 늘릴 때도 **"판정은 코드, 문장은 AI"** 원칙을 유지합니다.

### 학부모 문의 답변 도우미 (후보)

| 단계 | 담당 | 내용 |
|---|---|---|
| ① 질문 분류 | AI | "이번 주 출석했나요?", "몇 시에 나갔나요?" 같은 문의를 정해진 유형(출석 여부 / 등·하원 시각 / 주간 요약 / 기타) 중 하나로 **분류만** 합니다. |
| ② 데이터 조회 | 코드 | 분류 결과에 따라 `attendance` 원본에서 해당 학생·날짜 값을 조회합니다. |
| ③ 답변 문장 | AI | 조회된 값만 사용해 정중한 답변을 작성합니다. 숫자·시각을 지어내지 않습니다. |
| ④ 발송 | 원장 | 원장이 확인한 뒤 복사해서 보냅니다. (자동 발송 없음) |

- "기타" 유형(수업 내용·상담 요청 등)은 AI가 답하지 않고 원장에게 넘깁니다.
- 학생을 식별하지 못하면 답하지 않습니다. (다른 학생 정보 노출 방지)
