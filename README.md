# 삼복출프 (SBCP) — 학원 출결 + AI 지난주 리포트

학생이 **2자리 번호**로 직접 등·하원을 체크하면 출석률·연속 출석·체류 시간을 코드가 자동으로 집계합니다.
AI는 그 집계 결과를 **리포트 문장으로 옮기는 일만** 맡습니다.

2026년 10월 버전(**v1.5**)부터는 리포트를 학부모에게 보내는 대신 **학생들이 학원 안에서 직접 보도록** 바꿨습니다.
등원할 때 **지난주 나의 리포트**가 뜨고, 출결 데스크에서는 **친구들의 지난주 리포트**가 돌아가며 보입니다.
서로의 기록을 보며 생기는 자극으로 출석 의지를 높이려는 것입니다.

- 배포 주소(웹): https://sbcp-attendance.vercel.app/
- 기능 명세: [`docs/서비스기획서.md`](docs/서비스기획서.md)

## 1. v1.5 (2026년 10월) 변경 사항

| 구분 | 내용 |
|---|---|
| 🆕 지난주 리포트 자동 생성 | 평일 **13:30**에 전체 학생의 지난주 리포트를 AI가 자동으로 작성하고, **14:00**에 실패하거나 빠진 학생만 다시 시도합니다. 원장이 누를 버튼은 없습니다. |
| 🆕 등원 팝업 | 등원하면 팝업에 **지난주 나의 리포트**(등급·출석·연속·평균 체류 + AI 한마디)가 함께 뜹니다. 리포트가 만들어지기 전에 등원했다면 그날은 통계만 보이고, 다음 등원부터 AI 한마디가 보입니다. |
| 🆕 친구 보드 | 출결 데스크 오른쪽 **지난주 리포트** 칸이 **4초마다** 친구 한 명씩 순환합니다. 드롭다운으로 친구를 골라 고정할 수 있고, 20초 뒤 다시 순환합니다. |
| 🆕 공개용 문장 톤 | 친구들이 함께 보는 글이라 **비교·질책 없이** 격려 위주로 씁니다. 지난주 출석이 0일인 학생은 순환에서 빠집니다. |
| 🔧 연속 출석 | 주말뿐 아니라 **등록한 휴원일도 건너뛰고** 연속으로 셉니다. (수요일이 휴원이면 화 → 목 출석도 연속) |
| 🔧 전체 휴원 주 | 한 주 전체가 휴원(운영일 0일)이면 전용 안내 문구가 나옵니다. |
| 🔧 백업 · 복구 | 백업 파일 이름에 날짜가 붙고(`acad_backup_2026-10-01.json`), 복구할 때 파일을 먼저 검사해 **무엇이 문제인지** 알려 줍니다. ([6절](#6-데이터-백업--복구-json)) |
| 🆕 로컬 실행 | `start_windows.bat` 더블클릭으로 인터넷 배포 없이 학원 PC에서 실행할 수 있습니다. ([4절](#4-로컬-pc-설치-방법-windows)) |

> 기존 데이터는 그대로 이어집니다. 저장 이름(`acad-atd-03_1.4`)을 바꾸지 않았기 때문입니다.
> 단, **같은 주소**로 접속해야 합니다. 주소가 다르면 데이터가 안 보입니다. → [7절 Q1](#q1-학생출결-데이터가-전부-사라졌어요)

## 4. 로컬 PC 설치 방법 (Windows)

학원 데스크 PC 한 대에 설치해 쓰는 방법입니다. 한 번만 설정해 두면 이후에는 **아이콘 더블클릭 한 번**으로 켜집니다.

> **어떤 방식을 써야 하나요?**
> - **로컬 실행 (이 절)**: 학원 PC에서 `start_windows.bat`로 켭니다. 인터넷은 AI 문장을 만들 때만 필요합니다.
> - **웹 주소 접속 ([8절](#8-웹-배포-버전-vercel))**: 크롬에서 배포 주소를 엽니다. 설치는 필요 없지만 배포 관리가 필요합니다.
>
> 두 방식은 **데이터를 공유하지 않습니다**(주소가 다르기 때문). 한 가지를 정해 계속 쓰고,
> 옮길 때는 [6절 백업·복구](#6-데이터-백업--복구-json)로 데이터를 옮기세요.

### 4-1. 파이썬 설치 (처음 한 번)

로컬 서버는 파이썬 기본 기능만 사용하므로 **추가 설치(pip)는 필요 없습니다.**

1. https://www.python.org/downloads/ 에 접속해 **Download Python 3.x** 버튼을 누릅니다. (3.8 이상이면 됩니다)
2. 받은 설치 파일을 실행합니다.
3. ⚠️ 첫 화면 아래쪽의 **"Add python.exe to PATH"** 에 **반드시 체크**합니다.
4. **Install Now** 를 누르고 끝날 때까지 기다립니다.
5. 확인: `Win + R` → `cmd` 입력 → 검은 창에 `py --version` 입력 → `Python 3.x.x` 가 나오면 성공입니다.

### 4-2. 프로그램 파일 받기

1. GitHub 저장소 페이지에서 초록색 **`<> Code`** 버튼 → **Download ZIP** 을 누릅니다.
2. 받은 ZIP 파일을 **마우스 오른쪽 → 압축 풀기**로 풉니다.
   - ⚠️ ZIP 안에서 바로 실행하지 말고 **반드시 압축을 푼 뒤** 사용하세요.
3. 풀린 폴더를 찾기 쉬운 고정 위치로 옮깁니다. 예: `C:\SBCP`
   - ⚠️ 설치 후에는 **폴더 위치와 이름을 바꾸지 마세요.** 바탕화면 바로가기(4-5)가 깨집니다.
   - 한글이나 공백이 없는 경로를 권장합니다. (`C:\SBCP` 좋음, `C:\새 폴더 (2)` 비권장)

### 4-3. Gemini API 키 넣기 (AI 문장용)

AI 리포트 문장을 만들려면 Google Gemini API 키가 필요합니다. 키가 없어도 **출결·통계·랭킹·보드의 숫자는 정상 동작**합니다. AI 한마디만 "준비 중"으로 표시됩니다.

1. https://aistudio.google.com/apikey 에서 **Create API key** 로 키를 만들고 복사합니다.
2. `C:\SBCP` 폴더 안에서 **마우스 오른쪽 → 새로 만들기 → 텍스트 문서** 를 선택합니다.
3. 파일 이름을 **`gemini_key.txt`** 로 정합니다.
   - ⚠️ 윈도우가 확장자를 숨기면 `gemini_key.txt.txt` 가 되기 쉽습니다.
     탐색기 상단 **보기 → 표시 → 파일 확장명**을 켜고 이름을 확인하세요.
4. 파일을 열어 **첫 줄에 키만** 붙여 넣고 저장합니다. (따옴표·공백·다른 글자 없이)

> 🔒 `gemini_key.txt` 는 **다른 사람에게 보내거나 인터넷에 올리지 마세요.** 이 파일은 저장소에 올라가지 않도록 설정되어 있습니다(`.gitignore`).
> 키를 PC 환경변수 `GEMINI_API_KEY` 로 넣어도 됩니다(파일보다 먼저 사용).

### 4-4. 실행하기

1. `C:\SBCP\start_windows.bat` 를 **더블클릭**합니다.
   - 처음에 "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행** 을 누릅니다.
   - "방화벽" 창이 뜨면 **허용** 을 누릅니다. (이 PC 안에서만 쓰는 연결입니다)
2. 검은 창에 아래처럼 나오고, 크롬(기본 브라우저)이 자동으로 열립니다.

   ```
   ====================================================
    삼복출프(SBCP) 출결 프로그램 - 로컬 실행
   ====================================================
    Gemini 키: 확인됨 (gemini_key.txt)

    주소: http://localhost:8000/
    이 검은 창을 닫으면 프로그램이 멈춥니다. 수업 중에는 최소화만 해 두세요.
   ```
3. 브라우저가 열리지 않으면 크롬 주소창에 **`http://localhost:8000`** 을 직접 입력합니다.

> ⚠️ **검은 창을 닫으면 프로그램이 멈춥니다.** 최소화(`_`)만 해 두세요.
> ⚠️ 주소는 항상 **`http://localhost:8000`** 으로 접속하세요. `127.0.0.1:8000` 이나 `index.html` 파일을 직접 여는 방식은 **다른 주소로 취급되어 데이터가 따로 저장됩니다.**

### 4-5. 편하게 쓰기 위한 설정 (권장)

**바탕화면 바로가기**
- `start_windows.bat` 마우스 오른쪽 → **더 많은 옵션 표시 → 바로 가기 만들기** → 만들어진 바로가기를 바탕화면으로 옮깁니다.

**PC를 켜면 자동 실행** (13:30 자동 생성을 놓치지 않으려면 권장)
1. `Win + R` → **`shell:startup`** 입력 → Enter. 시작프로그램 폴더가 열립니다.
2. 위에서 만든 바로가기를 이 폴더에 **복사**해 넣습니다.
3. 이제 PC를 켜고 로그인하면 프로그램과 브라우저가 자동으로 열립니다.

**절전 모드 끄기**
- 지난주 리포트 자동 생성은 **브라우저 화면이 열려 있는 동안** 13:30과 14:00에 동작합니다.
- **설정 → 시스템 → 전원** 에서 "화면 끄기"는 괜찮지만 **"절전 모드"는 "안 함"** 으로 두세요. PC가 잠들면 자동 생성이 멈춥니다.

**크롬 전체 화면**
- 학생용 데스크로 쓸 때는 `F11` 로 전체 화면을 켜면 주소창·탭이 숨겨져 깔끔합니다. (끄기: 다시 `F11`)

### 4-6. 새 버전으로 업데이트하기

1. **먼저 데이터를 백업합니다.** 데이터 관리 → **전체 데이터 백업** ([6-1](#6-1-백업하기))
2. 검은 창을 닫아 프로그램을 끕니다.
3. 새 ZIP을 받아 압축을 풀고, **`gemini_key.txt` 를 제외한 파일들을** 기존 `C:\SBCP` 폴더에 덮어씁니다.
4. `start_windows.bat` 로 다시 켭니다. 주소(`localhost:8000`)가 같으므로 **데이터는 그대로 남아 있습니다.**
5. 혹시 데이터가 안 보이면 1번에서 받은 백업 파일로 복구합니다.

### 4-7. macOS에서 쓰는 경우

1. 파이썬 설치: 터미널에서 `python3 --version` 이 안 되면 python.org 에서 설치합니다.
2. 4-2, 4-3과 같이 폴더를 두고 `gemini_key.txt` 를 만듭니다.
3. 처음 한 번 터미널에서 `chmod +x start_mac.command` 를 실행합니다.
4. 이후 `start_mac.command` 를 더블클릭하면 켜집니다.

## 5. 매일 운영 방법

| 시각 | 하는 일 | 누가 |
|---|---|---|
| 13:30 전 | PC를 켜고 프로그램 실행 (자동 실행 설정 시 생략) | 원장 |
| 13:30 | 지난주 리포트 자동 생성 1차 (지난주 출석 학생 전원, 한 명씩 차례로) | 자동 |
| 14:00 | 1차에서 실패·누락된 학생만 2차 재시도 | 자동 |
| 수업 중 | 학생이 번호 2자리로 등원 → 팝업에서 지난주 리포트 확인 → 하원 때 번호 한 번 더 | 학생 |
| 수업 중 | 출결 데스크 오른쪽 보드에서 친구들의 지난주 리포트가 4초마다 순환 | 자동 |
| 퇴근 전 | **데이터 관리 → 전체 데이터 백업** (주 1회 이상 권장) | 원장 |

- 자동 생성 상황은 **주간 리포트** 화면 아래 **"지난주 리포트 자동 생성"** 칸에서 확인합니다.
  - `13:30 시도함` / `14:00 시도함` 과 `n건 생성 · n건 미생성` 이 표시됩니다.
  - 미생성분이 남아 있으면 **[미생성분 지금 생성]** 버튼으로 바로 다시 시도할 수 있습니다(비상용).
- PC를 14:00 이후에 켰다면 켜자마자 1차가 실행되고, 끝나는 대로 2차가 이어서 실행됩니다.
- 주말에는 자동 생성이 동작하지 않습니다.
- **휴원일**은 **설정 → 휴원일 관리**에 미리 등록해 두세요. 출석률 분모와 연속 출석 계산에서 제외됩니다.
  (음력 공휴일·대체공휴일은 직접 추가해야 합니다)

## 6. 데이터 백업 · 복구 (JSON)

모든 데이터는 **브라우저 안(localStorage)** 에 저장됩니다. 다음 경우에는 데이터가 사라지거나 안 보일 수 있습니다.

- 브라우저의 "인터넷 사용 기록 삭제"에서 **쿠키 및 사이트 데이터**를 지움
- 다른 PC나 다른 브라우저로 옮김
- 접속 주소가 바뀜 (예: 웹 주소 ↔ `localhost:8000`)

그래서 **정기적인 백업 파일(JSON)** 이 유일한 안전장치입니다.

### 6-1. 백업하기

1. 왼쪽 메뉴 **데이터 관리** 를 누릅니다.
2. **⬇️ 전체 데이터 백업 (내보내기)** 를 누릅니다.
3. `다운로드` 폴더에 **`acad_backup_2026-10-01.json`** 처럼 날짜가 붙은 파일이 저장됩니다.
4. 이 파일을 **USB·클라우드(구글 드라이브 등)에도 한 부** 복사해 두세요.

| 포함되는 것 | 포함되지 않는 것 |
|---|---|
| 학생 명단, 전체 출결 기록, 연속·월간 통계, 휴원일, 학원 설정, **지난주 리포트(최근 8주)** | 리포트 생성 이력 목록, 리포트 캐시, 화면 테마(다크 모드) |

> 이력 목록은 필요하면 **리포트 발송 이력 → CSV 내보내기**로 따로 보관하세요.

### 6-2. 복구하기 (불러오기)

⚠️ 복구하면 **현재 데이터가 백업 파일의 내용으로 전부 바뀝니다.** 순서대로 진행하세요.

1. **(권장) 지금 데이터부터 백업합니다.** 6-1을 한 번 해 두면 잘못 복구해도 되돌릴 수 있습니다.
2. 반드시 **평소 쓰는 주소**로 접속합니다. (로컬이면 `http://localhost:8000`)
   - ⚠️ **시크릿(비공개) 창에서는 복구하지 마세요.** 창을 닫으면 복구한 데이터가 사라집니다.
3. **데이터 관리** → **⬆️ 백업 파일 불러오기 (복구)** 를 누릅니다.
4. 파일 선택 창에서 **`acad_backup_날짜.json`** 파일을 고릅니다.
   - 가장 최근 날짜의 파일을 고르세요. 예전 버전의 `acad_backup.json`, `acad_backup (1).json` 도 불러올 수 있습니다.
   - ❌ **CSV 파일(출결기록_…csv, 출결랭킹_…csv)은 복구용이 아닙니다.** 엑셀 열람용입니다.
5. 확인 창에 **파일 이름·백업 시각·학생 수·출결 기간**이 나옵니다. 맞는지 확인하고 **확인**을 누릅니다.
6. "✅ 데이터 복구가 완료되었습니다" 안내 후 화면이 새로고침됩니다.
7. **학생 관리** 화면에서 학생 수를, **데이터 관리 → 출결 기록 CSV**에서 날짜를 확인합니다.

> 복구 직전의 데이터는 브라우저 안에 한 벌 따로 보관됩니다(`acad-atd-03_1.4-before-restore`).
> 실수로 잘못 복구했다면 이 README의 [7절 Q5](#q5-잘못된-파일로-복구해-버렸어요)를 참고하세요.

### 6-3. 복구 오류 메시지별 해결 방법

v1.5부터 복구할 때 파일을 먼저 검사하고, 문제가 있으면 **무엇이 잘못됐는지** 알려 줍니다.

| 화면에 나온 메시지 | 원인 | 해결 방법 |
|---|---|---|

| **… 번째 학생 정보가 손상되었습니다** | 파일을 직접 수정하다 번호·이름이 빠짐 | 수정하지 않은 원본 백업 파일을 사용하세요. |
| **파일을 읽지 못했습니다** | USB가 빠졌거나, 파일이 클라우드에만 있고 PC에 내려받아지지 않음 | 파일을 **바탕화면으로 복사**한 뒤 다시 고르세요. |
| **브라우저 저장 공간에 기록하지 못했습니다** | 시크릿 창이거나 저장 공간 부족 | **일반 창**에서 다시 시도하세요. |

## 7. 문제 해결

### Q1. 학생·출결 데이터가 전부 사라졌어요

대부분 **접속 주소가 달라진 경우**입니다. 브라우저는 주소별로 데이터를 따로 저장합니다.

| 이렇게 접속하면 | 저장소 |
|---|---|
| `http://localhost:8000` | A |
| `http://127.0.0.1:8000` | B (A와 다름!) |
| `index.html` 파일을 더블클릭 (`file:///…`) | C (A와 다름!) |
| `https://sbcp-attendance.vercel.app` | D (A와 다름!) |
| 크롬 ↔ 엣지, 다른 PC | 모두 다름 |

→ 평소 쓰던 주소로 다시 접속해 보세요. 그래도 없다면 [6-2 복구](#6-2-복구하기-불러오기)를 진행하세요.

### Q2. 검은 창이 잠깐 떴다가 바로 사라져요

- **파이썬이 없거나 PATH 체크를 빠뜨린 경우**입니다. [4-1](#4-1-파이썬-설치-처음-한-번)을 다시 진행하세요. (설치 프로그램 → **Modify** 또는 재설치 시 "Add python.exe to PATH" 체크)
- ZIP 안에서 바로 실행한 경우 → 압축을 푼 폴더에서 실행하세요.

### Q3. "8000번 포트를 이미 사용 중입니다"

- 프로그램이 **이미 켜져 있습니다.** 작업 표시줄에 검은 창이 또 있는지 확인하고, 브라우저에서 `http://localhost:8000` 으로 접속하세요.
- 창이 안 보이면 PC를 재시작하세요.

### Q4. AI 한마디가 계속 "준비 중"이에요

1. 검은 창에 **`Gemini 키: 확인됨`** 이 나오는지 확인합니다. "없음"이면 [4-3](#4-3-gemini-api-키-넣기-ai-문장용)을 다시 확인하세요(`gemini_key.txt.txt` 주의).
2. 검은 창에 `Gemini HTTP 오류: 503` 이 보이면 **Google 서버가 일시적으로 혼잡**한 것입니다. 14:00 재시도나 **[미생성분 지금 생성]** 버튼으로 다시 시도하세요.
3. `Gemini HTTP 오류: 400/403` 이면 키가 잘못되었거나 만료된 것입니다. 새 키를 만들어 넣으세요.
4. 인터넷 연결을 확인하세요. (AI 문장을 만들 때만 인터넷이 필요합니다)
5. 지난주 출석이 0일인 학생, 전체 휴원 주는 원래 AI 문장을 만들지 않습니다.

### Q5. 잘못된 파일로 복구해 버렸어요

1. 복구 **전에 받아 둔 백업 파일**이 있다면 그 파일로 다시 복구합니다.
2. 없다면 복구 직전 데이터가 브라우저에 보관되어 있습니다. 크롬에서 `F12` → **Console** 탭에 아래 한 줄을 붙여 넣고 Enter 하면 되돌아갑니다.
   (처음 붙여 넣을 때 경고가 나오면 안내대로 `allow pasting` 을 입력하고 Enter 한 뒤 다시 붙여 넣으세요.)
   ```js
   localStorage.setItem('acad-atd-03_1.4', localStorage.getItem('acad-atd-03_1.4-before-restore')); location.reload();
   ```

### Q6. 보드에 특정 학생이 안 나와요

- 지난주 **출석 0일**인 학생은 순환에서 제외됩니다. 드롭다운으로 직접 고르면 볼 수 있습니다.
- 새로 등록한 학생은 출석한 주가 끝나고 **그다음 주**부터 보드에 올라옵니다. (보드는 지난주 기록을 보여 주기 때문)

## 9. 설계 요약

**판정은 코드, 문장은 AI.** 출석률·등급·연속 출석은 전부 `js/main.js` 가 계산하고, AI에게는 확정된 숫자와 등급만 넘겨 문장만 쓰게 합니다. 같은 데이터로 몇 번을 만들어도 등급이 바뀌지 않게 하기 위해서입니다.

| 항목 | 기준 |
|---|---|
| 운영일 | 월~금 중 등록 휴원일 제외 |
| 등급 | 출석률로만 판정 — 최고 100% / 양호 80%↑ / 보통 60%↑ / 주의 60% 미만 |
| 연속 출석 | 직전 운영일에 출석했으면 +1 (주말·휴원일은 건너뜀) |
| 체류 시간 | 하원 시각 − 등원 시각, 하원 미체크는 0분으로 평균에 포함 |
| AI 모델 | Gemini (`api/report.py`), 타임아웃 25초, 자동 재시도 없음 (재시도는 14:00 슬롯이 담당) |
| 문장 톤 | 학부모 발송용 / 학생 열람용 / **지난주 보드용(peer, 비교·질책 금지)** |

API 명세, 예외 처리, 캐시 설계 등 자세한 내용은 [`docs/서비스기획서.md`](docs/서비스기획서.md)에 있습니다.

## 10. 개발 로그

### v1.5 — 2026년 10월 운영 버전

- **방향 전환**: 카카오톡 등 외부 알림은 사업자 심사와 연동 역량이 부족해 보류했습니다. 대신 리포트를 **학원 안에서 학생들이 서로 보는 방식**으로 바꿨습니다.
- **연속 출석 휴원일 반영**: 기존 `prevWeekday()` 는 주말만 건너뛰어, 휴원일이 낀 주에는 연속이 끊겼습니다. `prevOperatingDay()` 로 바꾸고, 연속 여부를 "직전 운영일에 출석했는가"로 판단하게 했습니다. 휴원일을 추가·삭제하면 전원의 기록을 원본 출결에서 다시 계산합니다.
- **자동 생성 시각**: 데스크 PC가 13:30쯤 켜지는 운영 환경에 맞췄습니다. 테스트 중 Gemini가 일시적으로 503(혼잡)을 반환하는 것을 확인해, 실패분만 다시 시도하는 14:00 슬롯을 두었습니다.
- **보드 공개 범위**: 출석 0일인 학생을 공개 순환에 올리면 망신이 될 수 있어 제외했습니다. 드롭다운 고정은 공용 PC에 방치되지 않도록 20초 뒤 자동으로 풀리게 했습니다.
- **복구 오류 개선**: 실패 후 같은 파일을 다시 고르면 반응하지 않던 문제(파일 선택값 초기화 누락)를 고쳤습니다. 저장에 실패해도 "성공"으로 표시되던 문제를 고쳤습니다. 원인별 안내 문구를 추가했고, 백업 파일명에 날짜를 붙였습니다.
- **로컬 실행**: 파이썬 기본 기능만으로 동작하는 `serve_local.py` 를 추가했습니다. 화면 파일 외의 파일(키 파일 등)은 내보내지 않고, 이 PC(127.0.0.1)에서만 접속되도록 했습니다.

## 11. AI 기능 확장 설계

앞으로 AI 기능을 늘릴 때도 **"판정은 코드, 문장은 AI"** 원칙을 유지합니다.

### 11-1. 학부모 문의 자동 응답 (후보)

| 단계 | 담당 | 내용 |
|---|---|---|
| ① 질문 분류 | AI | "이번 주 출석했나요?", "몇 시에 나갔나요?" 같은 문의를 정해진 유형(출석 여부 / 등·하원 시각 / 주간 요약 / 기타) 중 하나로 **분류만** 합니다. |
| ② 데이터 조회 | 코드 | 분류 결과에 따라 `attendance` 원본에서 해당 학생·날짜 값을 조회합니다. |
| ③ 답변 문장 | AI | 조회된 값만 사용해 정중한 답변을 작성합니다. 숫자·시각을 지어내지 않습니다. |
| ④ 발송 | 원장 | 원장이 확인한 뒤 복사해서 보냅니다. (자동 발송 없음) |

- "기타" 유형(수업 내용·상담 요청 등)은 AI가 답하지 않고 원장에게 넘깁니다.
- 학생을 식별하지 못하면 답하지 않습니다. (다른 학생 정보 노출 방지)

### 11-2. 여러 기기 동기화 (선행 과제)

지금은 데스크 PC 한 대의 브라우저에만 데이터가 있어, 학생 휴대폰에서 자기 리포트를 볼 수 없습니다.
서버 저장소로 옮기면 개인 열람과 학부모 문의 응답이 가능해집니다. 다만 로그인·개인정보 보호 설계가 먼저 필요합니다.
